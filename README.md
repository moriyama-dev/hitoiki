# Hitoiki（一息）

休憩時間を画面全体で知らせるポモドーロタイマーです。GNOME 向けに作っています。

作業時間が終わると、すべてのモニターに半透明の休憩画面が重なり、中央に「お疲れ様！一息つきましょう。」と表示されます。上部に小さな通知が出るだけのタイマーでは休憩を見逃してしまう、という人のためのアプリです。

> **開発中です。** まだ使える状態ではありません。

## 予定している機能

- 作業25分、休憩5分、4回ごとに長い休憩15分（時間は変更できます）
- 休憩時間になると、モニターごとに半透明の全画面の休憩画面を表示
- 休憩の残り時間の表示と「休憩をスキップ」ボタン
- apt でのインストールと自動更新

## 動作環境

- Ubuntu 24.04 以降（GNOME）
- Python 3、GTK 4、libadwaita

## 開発

必要なパッケージを入れてから、リポジトリの直下で起動します。

```sh
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1
./bin/hitoiki
```
